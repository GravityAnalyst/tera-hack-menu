## 🧩 About

**TERA Menu** is a curated list of TERA open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD hints, menu structure notes
- **Quality-of-Life Helpers** — config notes, loot tracker notes, map overlays
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Menu Overlay — practice reading layouts and rotations
- HUD Notes — visualize cooldowns and resource flow
- Replay Notes — record and review session notes
- Speed Notes — adjust editor playback for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse gear, colors, and appearance notes
- Custom Skin Notes — organize character cosmetics
- Map Overlay — improved zone and dungeon visibility

### Aimbot
- Practice Mode Notes — segment study on any encounter
- Aim Notes — chain complex rotations in the editor
- Movement Notes — review traversal patterns
